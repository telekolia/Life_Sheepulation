# SPEC-001: цель животного и назначение маршрута

Статус: verified · Дата: 2026-10-11 · Решение: подтверждено владельцем в чате.

## Проблема и результат

ID пищевой цели дублируется в entity и PathComp. Движение обращается к
сущности цели даже при готовом пути, поэтому удаление цели вызывает KeyError.
Падальщик не строит маршрут, а клетка трупа блокирует BFS.
Разделяем выбор сущности, построение маршрута и выполнение шагов.
Связи: REQ-FOOD-02/03/04, REQ-LIFE-07, REVIEW-02/04.

## Scope и правила

- Animal.target_id хранит идентичность пищевой цели; отсутствие — None.
- PathComp хранит destination (независимую Position) и path; ID цели там нет.
- find_path получает координаты, возвращает bool: True также при нуле шагов,
  если зона назначения уже достигнута. False очищает старый маршрут.
- Для еды BFS ищет доступную клетку на расстоянии ≤1 от переданной позиции;
  destination сохраняет фактическую конечную клетку построенного маршрута.
- Movement выполняет готовые шаги без обращения к пищевой цели. После
  последнего шага останавливается; destination сохраняется до отмены/нового задания.
- Оба поведения отменяют маршрут при отсутствии пищи, после еды и переходе
  в chill. Уже съеденные трупы/незрелые кусты не используются.
- Сохраняем выбор ближайшей пищи, радиус травоядного 8 и поиск падальщика
  по всему миру. Коллизии, баланс и порядок систем прежние.
- Нет зрения, потери видимости, автоматического обхода динамического
  препятствия и перебора альтернативной пищи при недоступности ближайшей.

## Критерии приёмки

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| AC-01 | Маршрут к точке без цели | Движение до точки и остановка |
| AC-02 | Исходная Position изменена/цель удалена | Готовый маршрут и destination независимы |
| AC-03 | Прибытие / недоступное назначение | True с пустым путём / False с очисткой |
| AC-04 | Падальщик и блокирующий труп | Подход на ≤1 и однократное питание |
| AC-05 | Пища съедена другим | Поведение отменяет цель и старый маршрут |
| AC-06 | Травоядное и зрелый куст | Подход и питание с прежним эффектом |
| AC-07 | Клонирование PathComp | destination и path не разделяются |
| AC-08 | Загрузка шаблонов и HUD | Цель только в Animal; HUD читает её оттуда |

## Пример самостоятельного назначения

```python
if pathfinding_system.find_path(entity, Position(5, 3)):
    entity['MoveComp'].state = 'path'
```

Animal для такого маршрута не требуется. Движение остановится после
последнего шага; destination останется доступным для проверки результата.
