# SPEC-002: голодный падальщик ищет пищу в радиусе

Статус: verified · Дата: 2026-10-11 · Владелец подтвердил план в чате.

## Проблема и результат

Scavenger.max_finding_dis=8 не используется. При отсутствии трупов животное
исполняет chill-блуждание, хотя голодно. Теперь обнаружение ограничено
радиусом, недоступные трупы пропускаются, без доступной пищи строится
продолжаемый маршрут поиска в случайном направлении.
Связи: REQ-FOOD-03/04/05, новые REQ-FOOD-07/08, REVIEW-02/03.

## Scope и правила

- Труп обнаруживается при евклидовом расстоянии ≤max_finding_dis (8).
  Вода/стены не скрывают пищу: механика зрения не добавляется.
- Перебираются трупы от ближайшего к дальнему, равные расстояния сохраняют
  порядок мира. Выбирается первый с доступным подходом на ≤1; питание прежнее.
- Радиус ограничивает обнаружение; подход к найденной еде может огибать
  препятствия вне круга. Он проверяется существующим BFS на конечной карте.
- Если доступной пищи нет, Animal.is_searching=True и target_id=None.
  Выбирается случайное направление (один из восьми ориентиров), затем
  достижимая точка с наибольшим продвижением в этом направлении в круге
  радиуса. При равенстве предпочитается меньшая боковая удалённость.
  Если выбранное направление закрыто, используется самая дальняя достижимая
  точка. Равнозначные точки выбираются случайно.
- Достижимые точки и маршрут поиска не выходят из круга вокруг позиции
  в момент задания. Если карта мала/заблокирована, путь короче радиуса.
- Маршрут поиска сохраняется между ходами; перед каждым шагом повторяется
  обнаружение пищи. Найденная доступная пища заменяет поисковый маршрут.
- После завершения маршрута задаётся новый. Если следующий шаг заблокирован,
  поиск перестраивается от текущей позиции. При полном отсутствии доступных
  клеток животное остаётся hungry на месте, без chill-блуждания.
- После еды отменяются цель/маршрут/режим поиска. При сытости >70% применяется
  прежнее chill-поведение; расход сытости и порядок систем не меняются.
- Травоядное и его дефект выбора недоступного куста в эту задачу не входят.

## Критерии приёмки

| ID | Сценарий | Результат |
|---|---|---|
| AC-01 | Трупы на границе и за радиусом | Первый обнаруживается, второй нет |
| AC-02 | Ближний труп закрыт, дальний доступен | Выбирается доступный |
| AC-03 | Нет доступной еды | hungry, поисковый маршрут к достижимой точке |
| AC-04 | Несколько ходов без еды | Направление не выбирается заново каждый ход |
| AC-05 | Еда обнаружена по дороге | Поисковый путь заменяется подходом |
| AC-06 | Завершение/блокировка поискового пути | Следующее назначение / перестроение |
| AC-07 | Маленькая карта/полная блокировка | Короткий допустимый путь / остановка |
| AC-08 | Сытость, удаление цели, два потребителя | Без старого маршрута и повторной еды |

## План и проверка

Обновить AGENTS и правила проверки, Animal и Scavenger, добавить в BFS
получение достижимых координат без изменения маршрута. Проверить маленькие
миры, фиксированный RNG, текстовые снимки, существующие regression-тесты.
Окно не требуется: интерфейс/ввод не меняются. Обновить затронутые документы
и update; исторические review/specs сохранить.
