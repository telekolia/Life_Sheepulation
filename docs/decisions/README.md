# Архитектурные решения

ADR сохраняет причину выбора, альтернативы и последствия. Не каждое переименование требует ADR; изменение модели хранения, порядка фаз, RNG, коллизий или миграции компонентов — хороший кандидат.

Новый файл `ADR-002-topic.md`: дата; статус proposed/accepted/superseded; проблема; альтернативы; решение; последствия; ссылки на spec/REQ. Не приписывать владельцу согласование ещё не принятого предложения.
