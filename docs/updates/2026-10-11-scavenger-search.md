# 2026-10-11 — голодный падальщик ищет пищу

## Результат

Scavenger обнаруживает трупы в евклидовом радиусе 8 и проверяет подход от
ближнего кандидата к дальнему. Недоступный труп не удерживает выбор, если
доступен другой. При отсутствии доступной еды падальщик остаётся hungry,
задаёт маршрут поиска в случайном направлении и продолжает его между ходами.
Еда проверяется перед каждым шагом и прерывает поиск, когда обнаружена.

На малой/закрытой карте назначение ближе радиуса. Когда выбранное направление
закрыто, выбирается самая дальняя достижимая точка в пределах круга. При
полной блокировке животное остаётся на месте; chill-блуждание не вызывается.
После завершения пути назначается следующий участок; заблокированный
следующий шаг поискового маршрута приводит к его перестроению.

Animal.is_searching различает пищевой и поисковый маршруты, PathComp по-прежнему
хранит только координаты/шаги. BFS.reachable_positions получает достижимые
клетки внутри круга без изменения текущего маршрута. Неудачные проверки
подхода к трупам выполняются с отдельным PathComp в локальном представлении
entity, чтобы сохранить текущий поисковый маршрут.

согласованное изменение правила. Подход к обнаруженной еде может огибать
препятствия вне круга. Размер карты, баланс сытости/расходов, коллизии,
порядок систем, размножение и поведение травоядного не менялись.
