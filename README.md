# Life Sheepulation

Творческая симуляция маленькой экосистемы на Python и Pygame. Мир меняется дискретными ходами: овцы ищут созревшие кусты, голодают, стареют и взрослеют; мёртвые животные остаются в мире. Проект помогает изучать ECS и устройство игрового цикла без готового движка.

Это развивающийся прототип. В коде есть **гиена-падальщик** (`hyena`), но её спавн по умолчанию выключен. Питание и подход к доступному трупу исправлены; падальщик ищет доступную пищу в радиусе 8 и перемещается для поиска. Выбор альтернативного недоступному кусту у травоядного и согласование коллизий ещё требуют работы. Койоты из авторского замысла пока не реализованы. Полного хищничества, беременности, сохранения мира и редактора карты нет.

## Запуск

Запускай команды **из корня репозитория**, поскольку пути к JSON и текстурам относительные.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install pygame==2.6.1
.\.venv\Scripts\python.exe main.py
```

На 2026-10-11 проверки выполнены на Python 3.13.7 и Pygame 2.6.1 в существующем `.venv`. Это проверенная комбинация, не обещание поддержки всех версий. `requirements.txt` пока содержит текст `Plz, install pygame`, поэтому `pip install -r requirements.txt` использовать нельзя. Исправление манифеста включено в план стабилизации; зависимости в выполненных исправлениях не менялись.

## Что увидишь

Карта 40×40, 1600 тайлов, 15 взрослых овец, 5 ягнят и 3 куста. Размещение случайное. Ход запланирован каждые 0,2 секунды, отрисовка ограничена 60 FPS; при задержках кадра симуляция сейчас теряет часть времени. Окно 1920×1080, начальный zoom 0,4.

| Управление | Действие | Ограничение |
|---|---|---|
| WASD | Перемещение камеры | Сейчас зависит от событий окна, скорость нестабильна |
| Колесо мыши | Масштаб | Диапазон 0,1–5 |
| H | Показать HUD сущностей | HUD пока не учитывает камеру |
| Escape / закрытие окна | Выход | — |

Паузы и одиночного шага пока нет. Статистика существует в HUD, но выключена в `main.py`, отдельной клавиши нет. `settings.json` не читается.
